ДЕМО РЕАБИЛИТАЦИОННОГО ЦЕНТРА

Что нужно на демонстрационном ноутбуке:
- Windows 10/11;
- права администратора для установки Docker Desktop;
- включенная виртуализация в BIOS/UEFI;
- Docker Desktop с WSL2.

Быстрый запуск:
1. Скопируйте папку RMcodex-demo с флешки на ноутбук, лучше в C:\RMcodex-demo.
2. Откройте папку C:\RMcodex-demo.
3. Запустите START_DEMO.bat двойным кликом.
4. Если Docker Desktop не установлен, установите его, перезагрузите ноутбук и снова запустите START_DEMO.bat.
5. После запуска откройте http://localhost:8000/

Логины:
- admin / admin12345
- specialist1..specialist4 / specialist123

Что показывать:
- Панель: общая сводка.
- Расписание: календарь занятий.
- Получатели: карточки, представители, балансы.
- Карточка занятия: перенос, отмена, списание, email-согласование.
- Специалист: мобильный календарь, отметка проведено/не проведено, заявки на отгул и график.
- Очередь: решения по списанию, переносы, email-согласования, заявки специалистов.

Удаленный показ:
- если флешка не сработала, самый быстрый вариант — показать экран с вашего ноутбука;
- если нужен кликабельный доступ по ссылке, запустите START_REMOTE_DEMO.bat на вашем ноутбуке;
- для START_REMOTE_DEMO.bat нужен cloudflared: установите его или положите cloudflared.exe в папку tools;
- подробные варианты описаны в docs\demo\REMOTE_DEMO_OPTIONS.md.

Email-подтверждения:
- в карточке занятия отправьте письмо;
- в истории отправок нажмите "Ссылка";
- на открывшейся странице подтвердите или отклоните занятие;
- ответ появится в карточке занятия и в очереди администратора.

Остановка:
- запустите STOP_DEMO.bat.

Важно:
- без Docker Desktop демо не запустится;
- Docker Desktop может потребовать интернет при первой установке;
- Docker Desktop обычно требует перезагрузку после установки WSL2;
- если порт 8000 занят, остановите другое приложение или поменяйте порт в compose.yaml;
- локальная демо-почта не отправляет настоящие письма наружу.
