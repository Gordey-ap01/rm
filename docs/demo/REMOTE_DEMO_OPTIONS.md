# Варианты удаленной демонстрации

## Самый надежный вариант на сегодня

Показать систему с вашего ноутбука через демонстрацию экрана в Zoom, Google Meet, Telegram, VK Teams, Яндекс Телемост или другом сервисе. Руководителю нужен только браузер/мессенджер, а проект запускается на вашей машине.

Плюсы: почти не зависит от чужого ноутбука.  
Минусы: руководитель не кликает сам, если не дать удаленное управление экраном.

## Публичная временная ссылка через Cloudflare Tunnel

Этот вариант дает руководителю обычную HTTPS-ссылку. Проект остается запущенным на вашем ноутбуке, наружу открывается только временный туннель.

Что нужно на вашем ноутбуке:

- Docker Desktop уже работает;
- установлен `cloudflared`, либо файл `cloudflared.exe` лежит в `tools\cloudflared.exe`;
- интернет без жесткой блокировки Cloudflare.

Запуск:

```powershell
.\START_REMOTE_DEMO.bat
```

В окне появится ссылка вида:

```text
https://example-name.trycloudflare.com
```

Эту ссылку можно отправить руководителю. Логин: `admin` / `admin12345`.

Официальная команда Cloudflare Quick Tunnel: `cloudflared tunnel --url http://localhost:8000`.

## Удаленный доступ к вашему ноутбуку

Подходят AnyDesk, RustDesk, Chrome Remote Desktop, TeamViewer. Руководитель подключается к вашему компьютеру и кликает в уже запущенной системе.

Плюсы: не нужно переносить проект.  
Минусы: нужен установленный клиент удаленного доступа и разрешения безопасности.

## Развернуть на VPS

Нормальный вариант для пилота: арендовать небольшой сервер, поставить Docker, скопировать проект и поднять `docker compose`.

Плюсы: доступ по ссылке постоянно, не зависит от вашего ноутбука.  
Минусы: нужен сервер, домен/HTTPS желательно настроить отдельно, нужно закрыть демо-пароли.

## Внутри одной локальной сети

Если вы с руководителем в одном Wi-Fi, можно открыть систему с вашего ноутбука по локальному IP.

Шаги:

1. Запустить `START_DEMO.bat`.
2. Узнать IP: `ipconfig`.
3. На другом ноутбуке открыть `http://ВАШ-IP:8000/`.
4. Временно разрешить входящий порт 8000 в Windows Firewall.

Плюсы: без интернета наружу.  
Минусы: работает только в одной сети, Windows Firewall часто мешает.

## Почему флешка не является надежным вариантом

Флешка переносит файлы, но не переносит Docker Desktop, WSL2, виртуализацию, права администратора, сетевые политики и уже скачанные Docker-образы. Поэтому на чистом Windows-ноутбуке один файл `.bat` не может сам запустить Django/PostgreSQL без установки рантайма.

## Рекомендация

Для срочной демонстрации: экран-шаринг или `START_REMOTE_DEMO.bat` с Cloudflare Tunnel.  
Для тестирования руководителем в течение нескольких дней: VPS или ваш ноутбук с включенным туннелем на время теста.
