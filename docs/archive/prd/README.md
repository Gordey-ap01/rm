# Архив PRD

Файлы в этой папке сохранены для истории решений и не являются актуальным
продуктовым контрактом.

Канонический PRD: `docs/01-prd.md`.

Архивные документы нельзя удалять, но при расхождениях они не имеют приоритета
над каноническим PRD, принятыми ADR, актуальной доменной моделью и кодом.
