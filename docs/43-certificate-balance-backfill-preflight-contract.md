# Certificate Balance Backfill Preflight Contract

Дата: 2026-07-19

Статус: implemented as read-only preflight on 2026-07-19

Основание:
- `docs/42-certificate-balance-ledger-contract.md`
- `docs/decisions/ADR-002-balance-accounts-ledger.md`

## Цель

Перед массовым созданием счетов баланса для уже заведенных сертификатов получить
безопасную картину данных: какие сертификаты можно связать автоматически, какие требуют
ручной правки, а какие несут риск для будущих ограничений БД.

Этот срез нужен, чтобы не запускать backfill вслепую на production-данных.

## Границы среза

Первый срез только читает данные и показывает отчет.

Разрешено:
- посчитать все сертификаты;
- посчитать уже связанные сертификаты;
- посчитать несвязанные сертификаты;
- посчитать кандидатов на будущий backfill с положительным остатком;
- отдельно посчитать несвязанные сертификаты с нулевым остатком;
- показать проблемы данных и небольшие sample ID.

Запрещено:
- создавать `BalanceAccount`;
- создавать `LedgerEntry`;
- создавать `Payment`;
- менять `Certificate.balance_account`;
- менять `Certificate.remaining_amount`;
- менять договоры, расписание, payroll, гранты или статусы занятий;
- добавлять DB constraints;
- переименовывать поля;
- исправлять данные автоматически.

## Проверки preflight

Backfill-кандидат в первом приближении:
- `Certificate.balance_account IS NULL`;
- есть `funding_source`;
- `total_amount >= 0`;
- `remaining_amount > 0`;
- `remaining_amount <= total_amount`;
- даты не противоречат друг другу.

Информационная группа:
- несвязанные сертификаты с валидными данными, но `remaining_amount = 0`.

Проблемы данных:
- нет источника финансирования у несвязанного сертификата;
- отрицательная полная сумма;
- отрицательный остаток;
- остаток больше полной суммы;
- дата окончания раньше даты начала;
- связанный счет другого получателя;
- связанный счет не в рублях;
- источник сертификата и связанного счета различается;
- дубликаты непустого номера сертификата внутри одного получателя.

## Команда

Management command:

```powershell
.\.venv-test\Scripts\python.exe manage.py audit_certificate_balance_backfill
```

С деталями:

```powershell
.\.venv-test\Scripts\python.exe manage.py audit_certificate_balance_backfill --details
```

Команда должна печатать только счетчики и технические ID/sample groups. ФИО получателей
в preflight-вывод не добавлять, чтобы отчет было безопаснее пересылать и обсуждать.

## Acceptance Criteria

- Есть read-only сервис preflight в сертификатном сервисном слое.
- Есть management command для запуска отчета.
- Тесты доказывают корректные счетчики кандидатов, проблем и дублей.
- Тесты доказывают, что preflight не создает `BalanceAccount` и `LedgerEntry`.
- `makemigrations --check --dry-run` не создает миграций.
- Ruff, Django check и focused tests проходят.

## Следующие отдельные решения

После запуска preflight на production/staging можно принимать отдельные решения:

- ручная правка сертификатов без источника финансирования;
- ручная правка отрицательных сумм и некорректных дат;
- политика для нулевых остатков: не создавать счета или создавать пустые счета;
- safe backfill-команда для положительных остатков;
- переименование `Certificate.remaining_amount` в snapshot-поле;
- DB check constraints для сумм и дат;
- уникальность номера сертификата внутри получателя после анализа дублей.

Ни одно из этих решений не входит в первый read-only preflight.
