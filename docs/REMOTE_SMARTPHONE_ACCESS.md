# Удаленный доступ со смартфона

Смартфон не должен подключаться напрямую к базе данных. Правильная схема: смартфон открывает веб-интерфейс Django, а Django уже работает с PostgreSQL или SQLite. Так сохраняются логин, роли, журнал действий, CSRF-защита и бизнес-правила.

## Что уже есть

- Локальный веб-интерфейс работает на `http://127.0.0.1:8000/`.
- Docker Compose публикует приложение на порт `8000`.
- `START_REMOTE_DEMO.bat` поднимает Cloudflare Quick Tunnel для временной демонстрации через интернет.
- `START_LAN_DEMO.bat` поднимает приложение для смартфонов в той же Wi-Fi/локальной сети и показывает адрес вида `http://192.168.x.x:8000/`.

## Варианты доступа

### 1. Смартфон в той же Wi-Fi сети

Запустить `START_LAN_DEMO.bat` на компьютере с проектом. На телефоне открыть адрес, который покажет скрипт.

Требования:

- компьютер и смартфон в одной сети;
- Docker Desktop запущен;
- Windows Firewall разрешает входящие подключения к порту `8000`.

### 2. Временный доступ через интернет

Запустить `START_REMOTE_DEMO.bat`. Скрипт использует Cloudflare Quick Tunnel и выводит публичную ссылку `https://...trycloudflare.com`.

Подходит для демонстрации и коротких тестов. Не подходит как постоянная эксплуатация без дополнительной настройки безопасности.

### 3. Постоянная эксплуатация

Нужен мини-сервер или VPS:

- Docker + PostgreSQL;
- домен и HTTPS;
- резервные копии базы;
- отдельные пароли пользователей;
- выключенные тестовые пароли;
- ограничение публичных confirmation-ссылок по сроку действия и частоте запросов.

Прямо открывать PostgreSQL наружу нельзя. Наружу открывается только веб-приложение по HTTPS.
