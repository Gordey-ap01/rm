# Удалённый доступ со смартфона

Для смартфона нужен не прямой доступ к базе данных, а публичная веб-ссылка на Django-приложение. В этой версии проекта рабочая схема одна: запустить локальный сервер в Docker и открыть временный HTTPS-туннель через Cloudflare.

## Что это даёт

- смартфон открывает обычный сайт в браузере;
- не нужен VPN и не нужен общий Wi-Fi;
- база данных остаётся внутри компьютера или мини-сервера;
- доступ работает через интернет по ссылке `https://...trycloudflare.com`.

## Как запускать

1. На компьютере с проектом запустить `START_REMOTE_DEMO.bat`.
2. Дождаться, пока Docker поднимет Django-приложение.
3. Скопировать публичную ссылку Cloudflare из окна консоли.
4. Открыть ссылку на смартфоне.

## Что важно понимать

- смартфон не подключается к PostgreSQL или SQLite напрямую;
- он работает только через веб-интерфейс Django;
- для постоянной эксплуатации нужен отдельный сервер или VPS с доменом и HTTPS;
- для быстрой демонстрации и теста достаточно Cloudflare Quick Tunnel.

## Если туннель не поднялся

- проверь, что установлен Docker Desktop;
- проверь, что есть `cloudflared` или `tools\\cloudflared.exe`;
- если туннель недоступен, можно открыть локальный адрес `http://localhost:8000/` на том же компьютере;
- для телефона локальный адрес не подходит, ему нужна публичная ссылка.
