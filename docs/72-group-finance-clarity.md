Теперь при групповом формате обычные поля программы/оплаты скрываются,
показывается инструкция настроить каждого участника в карточке после сохранения.
Если новые общие значения уже набраны, они остаются видны; отправка формы
останавливается до явного нажатия «Настроить после сохранения» или
«Вернуть сохранённые значения». Кнопка возвращает два поля к исходным значениям
из `form.initial`, не меняя состав. После ошибки исходные значения берутся
из сохранённого состояния, а не из отклонённого POST.

Скрытые select сохраняют имена и значения в POST, не disabled. Backend,
схема, права, проверки принадлежности и защиты финансовой истории не менялись.
Сохранённые общие и отдельные привязки участников не очищаются автоматически.
Удаление основного получателя при его сохранённых привязках остаётся отдельным
случаем: форма предупреждает, а сервер может остановить сохранение.
